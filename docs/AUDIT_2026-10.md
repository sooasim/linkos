## 1. 방법

1. **기능 원장(197건)** — 각 항목의 description/acceptance 를 읽고, (a) UI 진입점이 존재하고 내비게이션(사이드바·Dock·화면 내 링크)에서 도달 가능한지, (b) API 라우트가 존재하는지, (c) acceptance 가 요구하는 정상/오류/권한거부/오프라인·재시도 경로를 실제로 실행하는 테스트가 있는지, (d) 관련 도메인 이벤트가 발행되는지 확인했다.
   - acceptance 문구는 197건 모두 같은 템플릿(“정상/오류/권한거부/오프라인 또는 재시도 경로에서 정의된 결과 + 감사 가능한 상태 변화 + 사용자 피드백”)이다. 그래서 기능별 고유 검증 외에 **횡단 규칙**(멱등 재시도, 감사 로그, 권한 거부)을 함께 점검했다.
   - 스크립트 점검: 원장에 인용된 테스트 파일 197건 전부 존재, 인용된 UI 경로 전부 존재, `/app/*` 페이지 31개 전부 다른 화면에서 링크됨(`/app/sync` 는 오프라인 충돌 시 `OfflineAgent` 에서만 노출 — 의도된 동작).

## 3. 신규 기능 (Meet → Exchange → Remember → Act)

모든 신규 기능은 기존 디자인 시스템 클래스(`surface`, `btn`, `chip`, `field`, `display`, `eyebrow`, `stagger`, `glow-border` 등)와 토큰만 사용한다(예외: 메일 서명 HTML·PNG·PDF·패스처럼 CSS 변수를 해석하지 못하는 **산출물**은 같은 팔레트 값을 리터럴로 인라인).

### X-001 메일 서명 생성기 — Act
- **무엇**: 내 Living Card로 HTML + 텍스트 서명 3종(클래식·한 줄·파스텔)을 만들고 복사. 링크는 `/p/{slug}?src=sig` (X-003 에서 출처별 집계).
- **안전**: 모든 값 `escapeHtml()`(속성·본문 공통), 링크는 `safeHref()` 로 http(s)/mailto/tel 만 허용, `<style>`·class 없이 인라인 CSS. 미리보기는 `sandbox` iframe. 카드 필드는 **교환 대상(business) ACL** 로 걸러서 trusted/partner/private 는 절대 포함되지 않음.
- **코드**: `packages/domain/src/shareKit.ts`, `services/api/src/modules/shareKit.ts#emailSignatures`, `GET /api/v1/me/share/signature`, UI `/app/me/share#signature` (`/app/me` → “공유 도구”).
- **테스트**: 도메인(3스타일, XSS 주입 차단, safeHref), API(ACL·로그인·타인 프로필 404), e2e(텍스트 서명·sandbox).

### X-002 화상회의 가상 배경 — Meet
- **무엇**: 이름·직함·회사·짧은 링크가 들어간 1920×1080 PNG(파스텔/다크). **클라이언트 canvas** 에서만 그리고, 사용자가 버튼을 눌러야 내려받음(서버로 이미지 전송 없음).
- **코드**: 레이아웃은 순수 함수 `backgroundLayout()`(오른쪽 상단 밴드, 긴 이름 자동 축소), 데이터 `GET /api/v1/me/share/background`, UI `/app/me/share#background`.
- **테스트**: 도메인(맞춤 크기·스타일), e2e(다운로드 → PNG 시그니처 + IHDR 1920×1080 확인).

### X-003 카드 조회 분석 — Remember
- **무엇**: 게스트 랜딩 열람·CTA 탭(tel/mailto/링크/Action Card)·vCard 저장·회신 수를 교환 세션/프로필별로, 30일 스파크라인과 함께 `/app/insights` 에 표시. 공유 도구 링크(서명/배경/지갑) 유입도 출처별로 집계.
- **개인정보**: `card_view_daily(profile_id, exchange_session_id, day, kind, count)` — **방문자 식별자 없음**(IP·쿠키·해시 모두 저장 안 함, 테스트로 컬럼 목록 고정). 카드 주인의 **분석 거부(opt-out)**, 방문자의 **GPC/DNT**, 주인 본인 조회는 집계하지 않음. opt-out 하면 지금까지의 집계도 삭제(감사 로그). 13개월 지난 일별 카운트는 워커가 삭제.
- **코드**: `services/api/src/modules/cardViews.ts`, 서버 집계 지점 `x/[token]/GuestLanding.tsx`·`p/[slug]/page.tsx`·`handoff.applyReply`, 클라이언트 `components/CardViewTracker.tsx`(브라우저 GPC/DNT 시 아예 전송 안 함), `POST /api/v1/card-views`(cta·vcard 만 허용, IP당 rate limit, 세션-프로필 일치 검증), `GET /api/v1/insights/card-views`, `GET|PATCH /api/v1/me/analytics-preference`, 설정 `/app/settings#assistant`.
- **테스트**: 도메인(시리즈·스파크라인·허용 규칙), API(세션별 집계, GPC/DNT/본인/세션 위조 무시, opt-out 삭제·감사), e2e(실제 게스트 브라우저 열람·CTA·vCard → 인사이트 숫자, GPC 브라우저 미집계, 설정에서 끄기).

### X-004 지갑 패스 — Exchange
- **무엇**: Apple Wallet `.pkpass`(generic pass: pass.json + 아이콘/로고 PNG + manifest.json + **PKCS#7 분리 서명**)와 Google Wallet generic object(+ 서비스 계정 RS256 서명 “저장” 링크).
- **서명**: `services/api/src/lib/pkcs7.ts` — `@peculiar/asn1-cms`·`asn1-schema`·`asn1-x509` **2.10.0 정확히 고정**(PeculiarVentures 유지 라이브러리)으로 CMS SignedData 구조를 만들고, 키·해시는 `node:crypto`. 서명 속성(contentType/signingTime/messageDigest)은 DER 정렬, 서명자 인증서 + WWDR 체인 포함, RSA·EC 키 지원. OpenSSL `cms -verify` 로 검증하는 테스트 포함(변조 시 실패도 확인).
- **설정 전**: `PASS_CERT`/`PASS_KEY`/`WWDR`/`PASS_TYPE_ID`/`PASS_TEAM_ID` 가 없으면 `GET /api/v1/me/wallet/apple` 은 `501 wallet_not_configured` 이고, UI 는 “아직 설정되지 않았어요”를 보여준다(다운로드 버튼 없음). Google 은 `GOOGLE_WALLET_ISSUER_ID`/`GOOGLE_WALLET_SA_EMAIL`/`GOOGLE_WALLET_SA_KEY`.
- **ACL**: 패스에도 business 범위 필드만. 발급은 `audit_logs`(`wallet.apple_pass_issued`, `wallet.google_link_issued`).
- **코드**: `packages/domain/src/shareKit.ts`(pass.json 빌더·검증·manifest·Google 객체), `services/api/src/modules/shareKit.ts`, 라우트 `/api/v1/me/wallet{,/apple,/google}`, UI `/app/me/share#wallet`.
- **테스트**: 도메인 4건(pass.json 유효성·식별자 검증·manifest·Google id), `pkcs7.test.ts` 3건, API(미설정 501, 테스트 인증서로 서명된 zip 구조·manifest SHA-1·OpenSSL 검증, Google JWT 검증), e2e(미설정 안내·501).

### X-005 만나기 전 30초 브리핑 — Remember → Act
- **무엇**: 확정된(approved) 캘린더 일정에 **아는 연락처**(일정의 연락처 → 미팅 참가자 → 참석자 이메일 순)가 있으면 N분 전(기본 30, 0=끔, 설정 가능) push + 알림함으로 “○분 뒤 ○○님과 「제목」” 브리핑을 1회 보낸다.
- **사실만**: 누구/마지막 만남(날짜·장소·횟수)/내 메모(조직 공유 노트 제외)/확정된 할 일/상대의 확인된 Offer·Need 만 재진술. Need↔Offer 대화 주제만 `ai_inferred` 로 “AI 추론” 라벨. 알림 본문에는 추론 문장을 넣지 않음. 기록이 없으면 “만들어 내지 않음”을 명시.

## 6. 남은 제한

- `docs/TRACEABILITY.md` / `scripts/traceability.mjs` 는 이 작업에서 편집하지 않았다. 원장에 X-001~X-007 과 G-07/G-08 테스트 매핑, G-09 의 오래된 표기·경로를 반영해야 한다.

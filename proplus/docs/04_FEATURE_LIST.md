### 검증 강도 4단계 (배지 발급 가능 여부)

| 강도 | 공개 표기 | 배지 |
|---|---|---|
| `self_declared` | 자기기재 | **불가** |
| `document_reviewed` | 서류 확인 | 가능 |
| `issuer_confirmed` | 발급기관 확인 | 가능 |
| `system_integrated` | 시스템 연동 | 가능 |

| 코드 | 공개 라벨 | 최소 강도 | 발급기관 필수 | 기본 TTL |

## 굵게 표시한 기능이 왜 특별한가

이 기능을 바꾸는 PR 은 해당 단위테스트도 함께 바꿔야 하고, 그 테스트가 제품 신뢰 모델의 방어선이다.
